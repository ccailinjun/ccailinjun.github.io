pm2

发表于2026-10-16|更新于2026-10-19|前端
|浏览量:

PM2的核心定位是Node.js应用的生产环境进程管理器，内置负载均衡，目标是让应用“永远存活”、崩溃自动重启、升级时零停机。

核心能力与场景

集群模式与零停机更新：只需pm2 start app.js -i max，PM2就会自动检测CPU核数，启动同等数量的子进程共享端口。更新代码时用pm2 reload,PM2逐个重启子进程，始终保留至少一个在运行，实现无中断服务。这对HTTP/WebScoket/TCP/UDP服务都有效。无需修改代码。
进程守护与开机：崩溃自动重启，pm2 start+pmw save组合可以让服务重启后应用自动恢复。进程列表保存在$HOME/.pm2/dump.pm2。
日志管理：自动捕获stdout/stdee，存储在~/.pm2/logs，通过pm2 logs实时查看。长期运行需安装pm2-logrotate模块防止磁盘占满。
多语言支持：除了Node.js，也可以管理Python、Bash等脚本，会自动匹配解释器。

配置文件

当启动参数较多或需要管理多个应用时，用ecosystem.config.js替代命令行。关键字段包括：name（应用名）、script（入口文件）、instance（实例数）、exec_mode（cluster或fork)、watch（文件监听）、max_memory_restart（内存超限重启）、以及env/env_production区分环境变量。

在容器中使用

Docker环境用pm2-runtiome替代pm2，它会以前台模式运行，适合作为容器CMD。注意：容器本身已有重启策略时，额外用PM2会增加内存开销（约83MB）且违背单进程原则，PM2在容器中的价值主要在于其进程管理功能和集群模式。

与替代方案的关键对比

维度 PM2 systemd
内存开销 ~83MB 守护进程 0（系统原生）
集群模式 内置，零停机 reload 不支持
跨平台 Linux/macOS/Windows 仅 Linux
配置方式 ecosystem.config.js unit 文件

如果你已经在用systemd管理PM2本身，两者可以配合：PM2负责应用层集群和更新，systemd负责守护PM2守护进程并设置资源限制。

常用指令

启动与进程控制

指令 说明
pm2 start app.js 启动应用（默默守护进程）
pm2 start app.js –name “my-api” 启动并指定应用名称
pm2 start app.js –watch 监听文件变化，自动重启（适合开发）
pm2 stop <name | id | all> 停止进程 (保留在列表中)
pm2 restart <name | id | all> 重启进程（会话中断）
pm2 reload <name |id | all> 零停机重载（仅限cluster模式）
pm2 delete <name |id | all> 停止并从列表中删除

reload与restart的区别：restart直接杀掉进程在拉起，有短暂服务中断；有短暂服务中断；reload在cluster模式下逐个替换实现实例，实现零停机。

查看状态与监控

指令 说明
pm2 list (或ls / status) 列出所有的进程状态、CPU、内存
pm2 show <name | id> 查看单个进程的详细信息
pm2 monit 终端实时监控面板（CPU/内存/日志）
pm2 logs 实时流式查看日志
pm2 logs –lines 200 查看最近的200行日志
pm2 flush 清空日志文件

标准配置流程：先pm2 startup并执行生成命令->在启动你的应用->最后pm2 save固化列表。

开机自启与持久化

指令 说明
pm2 startup 生成系统开机启动脚本（按提示执行输出的命令）
pm2 save 保存当前进程列表，重启后自动恢复
pm2 resurrect 手动恢复之前保存的进程列表

配置文件

当需要管理多个应用或复杂参数时，建议使用配置文件：

指令 说明
pm2 ecosystem（或init） 生成ecosystem.config.js模板
pm2 start ecosystem.config.js 按配置文件启动所有应用
pm2 start ecosystem.config.js –env production 指定环境变量启动

使用小技巧

  • 传递参数：pm2 start app.js -- --port 3000,--后的参数会传给应用。
  • 内存超限重启：pm2 start app.js --max-memory-restart 500M，防止内存泄漏拖垮服务。
  • 日志轮转（生产必备）：安装pm2-logrotate模块自动切割日志，避免磁盘写满：pm2 install pm2-logrotate。
